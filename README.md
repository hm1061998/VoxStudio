# VoxStudio

VoxStudio is a self-hosted, multilingual web voice studio for deterministic, **strict non-AI** text-to-speech production. Speech is generated by **eSpeak NG 1.52.0** (rule-based formant synthesis) and shaped by conventional DSP (FFmpeg + Rubber Band). The application itself contains no neural, statistical, LLM, cloud, or cloned speech, and the compliance audit enforces that. **One opt-in exception (ADR 0008):** an AI voice engine (VieNeu-TTS) can run in a separate, self-hosted model service (`services/vieneu`, internal network only, preset voices only). It is off unless the operator configures it, is labelled "AI" everywhere in the UI, and never replaces or falls back from the rule-based engines. See `docs/upgrade/09-AI-ENGINE-CAPACITY.md` for capacity and paid-plan priority.

> **Default configuration (ADR 0009):** the product offers only the AI voices (`ENABLED_ENGINES=vieneu`, Vietnamese). eSpeak NG and the other rule-based engines are no longer shown unless an operator adds them to `ENABLED_ENGINES`; the sections below that describe eSpeak voices apply to that opt-in configuration. Without the model service no voice is available and `/health/ready` returns 503. Roles, the admin dashboard and account security are described in `docs/upgrade/10-SECURITY-AND-ACCESS.md`.

> Rule-based output is intelligible but clearly synthetic. VoxStudio does not claim human-like or emotional delivery. Presets are deterministic parameter bundles.

## What works

- **Vietnamese and English interface** (switch any time; Vietnamese by default for Vietnamese browsers), and a **Simple mode** (default) that shows only voice, speed, pitch, volume and pause. **Advanced mode** exposes every engine and DSP control. Three Vietnamese voices (northern, central, southern) with Vietnamese date/time/money/unit reading.

- Accounts: register, sign in/out, session rotation, change password, operator-issued password reset. Every project, segment, job and asset is owner-authorized; other users' resources return 404.
- Projects: create, rename, duplicate, archive, delete (audio files are removed too), search, sort, version snapshots and restore.
- Studio editor: segment list, Unicode text, split (cursor or sentences), merge, reorder (buttons or Alt+↑/↓), `[pause 500ms]` markers, `.txt` import, undo/redo, debounced autosave with saved/saving/failed status, local crash recovery, and 409 conflict handling.
- Voices: 36 eSpeak NG voices that passed automated QA (Japanese failed QA and is hidden). Each voice shows a support tier and its QA record, and you can play a live sample generated by the engine.
- Controls: engine-native settings (rate, pitch, intonation range, word gap, variant) and DSP settings (gain with clipping protection, time stretch, pitch shift, high-pass/shelf/presence EQ, compressor, exact pauses). Each control is labelled **Engine** or **DSP**.
- Text: deterministic English normalization (currency, %, dates, URLs, emails, abbreviations) and a "what the engine reads" view with engine-produced IPA phonemes. There is a pronunciation dictionary (literal or eSpeak phonemes, deterministic precedence, conflict view, JSON import/export).
- Rendering: PostgreSQL-backed job queue with an isolated worker. Progress is counted in real work units and streamed over SSE. Jobs can be retried or cancelled, and jobs lost to a crashed worker are recovered. The render cache is content-addressed, so editing one segment re-synthesizes only that segment.
- Export: WAV (16/24-bit), MP3, and OGG at 22.05, 44.1 or 48 kHz, mono or stereo. Every file is probed and fully decoded before it is offered. Downloads are authorized, and the browser player supports Range requests and shows a waveform with segment regions.
- Admin dashboard (`/admin`, administrators only): overview, users (role, status, plan), engines and voices, jobs, audit log. Ordinary users get 403 on every admin route.

## Quick start (local, Windows/macOS/Linux)

Prerequisites: Node.js ≥ 22, pnpm, PostgreSQL binaries (≥ 16), **eSpeak NG 1.52.0**, and a **compliant FFmpeg**: no `flite` or `whisper` (see [ADR 0004](docs/decisions/0004-ffmpeg-dsp-toolchain.md)). On Windows:

```bash
winget install --id eSpeak-NG.eSpeak-NG --exact
```

```bash
winget install --id Gyan.FFmpeg.Essentials --exact
```

Then:

```bash
pnpm install
```

```bash
pnpm db:start
```

`db:start` starts a project-local PostgreSQL on 127.0.0.1:5433 and writes `.env`.

```bash
pnpm build
```

```bash
pnpm start
```

`pnpm start` runs migrations, then the API (which also serves the web app) and the worker. Open http://localhost:4000 and register. The first account registered with an email listed in `ADMIN_EMAILS` becomes the administrator (only while no admin exists); later admins are promoted in the dashboard or with `node scripts/user-admin.mjs`.

For UI development with hot reload, run `pnpm dev:web` (port 5173, proxies `/api` to 4000) alongside `pnpm start`.

## Docker Compose (production baseline)

```bash
cp .env.docker.example .env.docker
```

Edit `.env.docker` and replace every `CHANGE_ME`, then:

```bash
docker compose up -d --build
```

Services: `caddy` (TLS reverse proxy), `api`, `worker` (internal network only, no internet route), `postgres`, plus a one-shot `migrate`. FFmpeg is compiled from pinned, checksum-verified source with only the components VoxStudio uses. See [docs/10-DEPLOYMENT.md](docs/10-DEPLOYMENT.md). **Not yet verified:** Docker was not available on the development machine (see the tracker).

## Commands

| Command                                              | Purpose                                                                                                                                                        |
| ---------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `pnpm build`                                         | Generate the Prisma client and build all packages and the web app                                                                                              |
| `pnpm test`                                          | Unit, engine/DSP integration and API integration tests (Vitest, real eSpeak NG + FFmpeg + PostgreSQL)                                                          |
| `pnpm test:e2e`                                      | Playwright browser journey (needs a running server)                                                                                                            |
| `pnpm lint` / `pnpm format:check` / `pnpm typecheck` | Static checks                                                                                                                                                  |
| `pnpm audit:compliance`                              | Compliance audit: no AI in the application (dependencies, endpoints, model files, FFmpeg filters, engine version, MBROLA); AI engine isolation when configured |
| `pnpm qa:voices`                                     | Re-run automated voice QA and write `config/voice-qa-report.json`                                                                                              |
| `pnpm user:reset-password <email>`                   | Issue a one-time password reset code (no email service is assumed)                                                                                             |
| `node scripts/backup.mjs backup\|verify\|restore`    | Database and audio backup with restore verification                                                                                                            |

## Architecture

```text
apps/web        React 19 + Vite + Tailwind + TanStack Query + Zustand + WaveSurfer
apps/api        NestJS 11: auth, projects, catalog, render planning, SSE, assets, admin
apps/worker     Claims jobs (SKIP LOCKED), synthesizes, applies DSP, assembles, encodes, validates
packages/core   eSpeak adapter, capabilities, normalization, pronunciation, DSP, WAV, cache keys, storage
packages/db     Prisma schema + migrations (PostgreSQL)
packages/contracts  Shared zod schemas, DTOs, error codes
config/         Voice allowlist, QA corpus, QA report
docs/decisions  ADRs 0001–0004
```

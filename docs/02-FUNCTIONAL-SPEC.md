# 02 — Functional Specification

## Modules

### 1. Identity and workspace

- Sign up/sign in/sign out.
- User profile and password reset flow.
- Workspace ownership and membership model (single owner in initial release).
- Every API read/write must enforce workspace ownership.

### 2. Dashboard and projects

- Create, rename, duplicate, archive, delete project.
- Search and sort projects.
- Show last edited time, locale, render status, and latest export.
- Confirm destructive actions.
- Autosave with visible saved/saving/error state.

### 3. Text editor

- Plain-text editor with Unicode-safe editing.
- Paste text and import TXT initially.
- Split by paragraph/sentence; allow manual split and merge.
- Reorder segments.
- Preserve punctuation and source text.
- Word/character counts and estimated duration clearly labeled as estimates.
- Insert pause markers.
- Per-segment locale, engine, voice, and settings.
- Bulk apply voice/preset to selected segments.
- Undo/redo for editor operations.
- Import DOCX/SRT only after parser and security tests.

### 4. Text normalization

- Locale-specific rules for numbers, dates, currency, abbreviations, symbols, and URLs.
- Provide a preview of normalized text before synthesis.
- Do not use language-model normalization.
- Keep original text unchanged; store normalized text or normalization result as derived data.
- Unknown rules should preserve text or request user correction rather than guess silently.

### 5. Voice catalog

- List approved engines and voices.
- Filter by locale, accent, engine, and supported controls.
- Voice sample must be generated by the actual engine or be a clearly licensed supplied sample.
- Display engine limitations and license attribution where required.
- Disabled/unverified voice packages are not selectable.

### 6. Voice settings

- Speed, pitch, volume, pause, emphasis, and intonation only where supported.
- Distinguish engine-native controls from DSP post-processing.
- Provide reset-to-default and preset save/apply.
- Validate ranges on both client and server.
- Never imply a control has an effect if adapter cannot implement it.

### 7. Pronunciation dictionary

- Per-user/workspace entries with locale scope.
- Exact phrase or token matching; deterministic precedence.
- Support engine-specific phoneme/phonetic representation only when documented.
- Preview entry against selected voice.
- Detect conflicting entries and show resolution order.
- Export/import dictionary JSON.

### 8. Audio preview and timeline

- Preview a segment or selected range.
- Play/pause/stop/seek.
- Show waveform and segment boundaries.
- Display loading, failed, and stale-audio states.
- Segment changes invalidate only affected derived audio.
- Timeline edits are non-destructive and versioned.

### 9. Rendering

- Queue segment synthesis and final assembly.
- Show queued/running/completed/failed/cancelled states.
- Progress is based on completed work units, not fabricated percentages.
- Retry failed work safely.
- Cancel queued or cancellable running work.
- Preserve previous successful export if a new render fails.
- Cache based on all synthesis-affecting inputs.

### 10. Export

- WAV PCM required.
- MP3 supported when encoder is installed and redistribution/use license reviewed.
- OGG optional.
- Configure sample rate, channel count, bit depth/bitrate where supported.
- Validate output file metadata and decode test before marking complete.
- Download uses authorized, expiring access or authenticated streaming.

### 11. Administration

- Inspect engine versions and health.
- Enable/disable engine and voice package.
- Manage approved locale catalog.
- View job failures and storage usage.
- No arbitrary shell command execution from admin UI.

## Core states

Project: draft, rendering, rendered, archived.  
Segment audio: missing, stale, queued, rendering, ready, failed.  
Render job: queued, running, succeeded, failed, cancelled.

## Error handling

Use stable error codes, human-readable messages, and retry guidance. Do not expose filesystem paths, command lines, stack traces, or secrets to clients.

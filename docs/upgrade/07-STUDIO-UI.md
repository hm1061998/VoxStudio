# 07 — Voice Studio UI for the multi-engine architecture

Status (2026-10-31): implemented and tested against the real API and the real eSpeak NG engine. No recorded-unit (`vnunit`) voice can be selected yet (no licensed data), so the UI paths specific to a recorded voice are covered by unit and API tests only, not by a browser run.

The existing design system, routes and workflows are unchanged. Everything below was added to existing components.

## Where each requirement lives

| Requirement                                                      | Where                                                                                                                                                                                                                                                         | Notes                                                                                                                                                     |
| ---------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Voice name, language, accent, engine, dataset status             | Studio Inspector (voice summary), Voices page                                                                                                                                                                                                                 | Dataset status: "Rule-based voice: there are no recordings", or "Recordings complete/incomplete" from the dataset report                                  |
| Preview audio of a voice                                         | Inspector "Listen to this voice", Voices page                                                                                                                                                                                                                 | A normal preview job: the server synthesizes the voice's sample text with that voice and engine                                                           |
| Engine and capabilities                                          | Inspector (Advanced): engine name, method, counts of engine / audio-processing / unavailable controls and an explanation; per-control badges; Voices page table                                                                                               | "Engine" = made by the engine, "Audio processing" = DSP after synthesis, "Not supported" = disabled (hidden in Simple mode)                               |
| Rate, pitch, volume, pauses, prosody controls                    | Inspector tabs                                                                                                                                                                                                                                                | Only controls the voice's capabilities declare; the server rejects anything else                                                                          |
| Vietnamese regional accent selection                             | Inspector "Regional accent"                                                                                                                                                                                                                                   | Shown only when installed voices of the same locale have more than one accent; lists only installed accents                                               |
| Pronunciation dictionary access                                  | Editor "Add pronunciation…" (word prefilled from the selection) and a link to the full dictionary page                                                                                                                                                        | Writes a real dictionary entry; open "how it will be read" panels refresh                                                                                 |

Engine phonemes are shown separately |
| Enter text → select voice → change parameters → preview → listen | Editor + Inspector + "Listen"                                                                                                                                                                                                                                 | Unchanged workflow                                                                                                                                        |
| Compare settings                                                 | "Previews to compare": every preview of the paragraph is kept (12 per project, in memory) with its voice, the engine the server recorded, a real audio player and the differences from the paragraph's current settings; tick two to see exactly what differs | Differences come from the stored settings of each preview, not from the labels                                                                            |
| Apply to a paragraph or the project                              | Per preview: "Use these settings for this paragraph" / "Use for all paragraphs"; Inspector: "Apply this voice and settings to all paragraphs"                                                                                                                 | Text is never changed; paragraphs in another language are skipped and counted                                                                             |

| Switching voice or engine                                        | Settings the new voice cannot honour are reset or clamped and listed; server validation unchanged                                                                                                                                                             | `reconcileSettings`                                                                                                                                       |

## API additions

- `NormalizationPreviewDto.diagnostics` (Vietnamese only, `null` otherwise).
- `AssetSummaryDto.engines` and `.voices` (derived from the stored engine snapshot; old assets without a snapshot field return empty lists and the UI shows nothing rather than guessing).

## Evidence

- Vitest 231/231 (was 227): `takes.test.ts`, API tests for diagnostics and render provenance.
- Playwright 4/4: the new test drives the whole flow in a browser against the real server: Vietnamese project, accent switch, voice sample, two previews (different voice and rate) whose audio files are fetched and checked as different RIFF/WAV files, comparison, apply to all, tone table, unreadable word, pronunciation entry that clears the warning, render, and the engine label. Console and 5xx errors are asserted empty.
- Screenshots at 1280 px and 820 px width were inspected; at tablet width the Inspector remains the existing drawer. After the first screenshot the editor column and the Inspector header were made scrollable because the new panels were clipped.

## Not done / limitations

- No automated accessibility audit (axe) was run. Keyboard operation was checked only for the flows the tests drive; new controls use native elements, labels and `role="status"` messages.
- Previews to compare live in memory for the open project: they are lost on reload (the audio assets still exist on the server for their normal retention period).
- The Vietnamese accent selector, dataset status text and engine explanation for a **recorded** voice have not been seen in a browser.
- The new-project dialog still preselects the first Vietnamese voice alphabetically (Central).
- Engine display names come from a small client table.
- The tone table is orthographic: it does not model dialect tone merging or predict how any engine pronounces a syllable.
- Two full `pnpm test` runs failed with a vitest "Channel closed" worker error immediately after Playwright runs; four later runs passed (231/231). I did not find the cause; it did not reproduce in isolation.
